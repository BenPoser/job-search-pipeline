# Learnings

The shape of `my/learnings.md`. Written by `/log-outcome`, read by `/find-jobs` and `/apply`.

Everything here is a plain-language observation, not a weight or a model. A job search produces
a few dozen applications, most ending in silence, which cannot support anything statistical
(`docs/adr/0004`). What it can support is noticing things, which is genuinely useful when it is
described honestly.

**You can edit or delete any line in this file.** You know things about your own search that the
log does not. If an observation is wrong, remove it; nothing else depends on it.
